🧲 TORRSERVER
  • 1Открыть TorrStream → Настройки → Настройки TorrServer
  • 2TorrServer на самой приставке: включить «Использовать TorrServer, установленный на этом устройстве» и нажать «Скачать TorrServer»
  • 3TorrServer на другом устройстве: кнопка «Найти TorrServer в сети» или ввести адрес вручную (пример: 192.168.1.30:8090)
📺 LG webOS
📺 LG webOS ▼
📥 СКАЧАТЬ ПРИЛОЖЕНИЕ (IPK)
  • 1TorrStream-webOS.ipk — обычное приложение, работает на любом LG
  • 2TorrStream-webOS-TorrServer.ipk — отдельное приложение со встроенным TorrServer. Сам TorrServer оно ставит только на телевизор с root (Homebrew Channel); без root работает как обычное
Ставится программой webOS Dev Manager: github.com/webosbrew/dev-manager-desktop — для Windows (.msi), macOS (.dmg), Linux (.deb, .AppImage) и Android-смартфона (universal.apk). Телевизор и компьютер (смартфон) — в одной сети, VPN выключен.
🔓 БЕЗ ROOT — РЕЖИМ РАЗРАБОТЧИКА
  • 1Зарегистрироваться на сайте LG Developer
  • 2На ТВ установить из магазина приложение Developer Mode, войти учётной записью LG, включить Dev Mode Status (ТВ перезагрузится) и Key Server
  • 3В Dev Manager добавить устройство → «Use Developer Mode»: имя, IP телевизора и passphrase — оба видны в Developer Mode на ТВ
  • 4Install → выбрать скачанный ipk → дождаться установки
⚠️ Сессия режима разработчика ограничена по времени — продлевайте её кнопкой Extend в приложении Developer Mode, иначе установленные так приложения пропадут. Подробно: webos-forums.ru
🔑 С ROOT — HOMEBREW CHANNEL
  • 1В настройках Homebrew Channel включить SSH и перезагрузить ТВ
  • 2В Dev Manager «Add device»: IP телевизора, порт 22, пользователь root, пароль alpine
  • 3Install → выбрать скачанный ipk. Перезагрузить ТВ при необходимости: вкладка Terminal → reboot
Подробно: telegra.ph — установка IPK-приложений. Встроенный TorrServer (сборка с TorrServer) работает только так — с root.
📺 НА ТЕЛЕВИЗОРЕ
  • 1Открыть TorrStream — он сам подключится к torrstream.online. Другой сервер: нажать ОК во время отсчёта на заставке
  • 2Настройки → TorrServer: адрес вашего TorrServer (пример: 192.168.1.30:8090) или, в сборке с TorrServer, «Использовать TorrServer, установленный на этом устройстве» → «Скачать TorrServer»
📺 Hisense / Vidaa — сервер TorrStream на одном из устройств в сети
📱 Android-телефон ▼
📥 ПРИЛОЖЕНИЕ TORRSTREAM SERVER
  • 1На телефоне открыть cash94.github.io/apk (на приставке — код 2252342 в Downloader) → TorrStream Server → «Рекомендуется»
  • 2Открыть TorrStream Server и нажать «Разрешить работу в фоне» — иначе система усыпит сервер с выключенным экраном
  • 3По желанию «Установить TorrServer» — тогда торренты будет отдавать сам телефон
  • 4Нажать «Запустить сервер» — на экране появится адрес для телевизора (пример: http://192.168.1.30:3000)
Телефон и телевизор должны быть в одной Wi-Fi сети. Если TorrServer работает на телефоне, его адрес телевизор подставит сам.
📺 Действия на телевизоре
  • 1Открыть браузер на ТВ и перейти по адресу vidaapp.cfd → найти TorrStream → установить
  • 2Перезагрузить телевизор
  • 3Запустить TorrStream и ввести адрес с экрана TorrStream Server (пример: http://192.168.1.30:3000)
  • 4В поле TorrServer указать адрес TorrServer (пример: http://192.168.1.30:8090)
