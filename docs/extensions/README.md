# Расширения TorrStream

Расширение (плагин) — один файл `.js`, который меняет интерфейс TorrStream.
Расширение может:
- добавлять кнопки в карточку фильма;
- открывать свои окна, которыми управляют пультом;
- менять оформление;
- строить свои меню на главной;
- хранить свои данные;
- ходить в интернет за сведениями.

Сервер TorrStream расширения не затрагивают. Работают они во всех версиях
TorrStream: в браузере, на Android TV, webOS, Tizen и VIDAA.

## Для зрителя: как поставить

1. **Настройки → Расширения.**
2. В ряду **«Каталог»** — проверенные расширения: ОК на плитке, и оно
   установлено.
3. Чужое расширение: плитка **«Добавить»** → ссылка на файл `.js` → «Сохранить».

Пультом:
- ОК на плитке расширения открывает меню: «Открыть», «Выключить», «Удалить»;
- удержание ОК удаляет расширение сразу.

**Если что-то сломалось.** В настройках расширения не действуют. Откройте
«Настройки → Расширения» и выключите проблемное или нажмите
«Выключить все расширения». В браузере можно открыть TorrStream с
`?noext=1` в адресе: расширения не запустятся вовсе.

## Безопасность

Каждое расширение работает в своей песочнице: это отдельный iframe без
доступа к странице приложения. Поэтому расширение **не видит**:
- пароль и адрес TorrServer, вход в учётку, токены;
- адрес сервера TorrStream, а также cookie и localStorage приложения;
- значения полей ввода;
- экран настроек.

Расширение **не может**:
- обращаться к серверу TorrStream, к TorrServer и к устройствам домашней сети;
- нажимать за человека то, что меняет данные (удалить, добавить в избранное).

Всё, что ему можно, оно делает через объект `TS`, и каждое действие
проверяет приложение.

Что расширение **видит**: какие фильмы вы открываете (название, год, id TMDB)
и содержимое экранов вне настроек. Ставьте расширения только из источников,
которым доверяете.

## Для автора: первое расширение за минуту

```js
// hello.js
TS.register({ name: 'Привет', version: '1.0', description: 'Первое расширение' });

TS.on('detail', function (item) {
  TS.ui.addButton({ id: 'hi', label: 'Привет', icon: 'smile' });
});

TS.on('button', function (e) {
  TS.toast('Вы открыли «' + e.item.title + '» (' + e.item.year + ')');
});
```

Положите файл туда, где он доступен по `https`, и установите его по ссылке
через плитку «Добавить».

### Где разместить файл

| Где | Ссылка | Примечание |
|---|---|---|
| GitHub Pages | `https://<вы>.github.io/<репо>/hello.js` | Лучший вариант |
| jsDelivr | `https://cdn.jsdelivr.net/gh/<вы>/<репо>@main/hello.js` | Кэширует надолго — меняйте версию в ссылке |
| raw.githubusercontent.com | `https://raw.githubusercontent.com/<вы>/<репо>/main/hello.js` | Тоже работает: код скачает приложение |
| Свой сервер в домашней сети | `http://192.168.x.x/hello.js` | Работает для отладки |

Если файл нельзя подключить как скрипт, приложение скачает его само. Так бывает
с адресами домашней сети или с ответом `text/plain`. Серверу при этом нужен
заголовок `Access-Control-Allow-Origin` (у GitHub он есть).

### Как попасть в каталог

Каталог — `msx/extensions/catalog.json` в репозитории
[cash94/cash94.github.io](https://github.com/cash94/cash94.github.io). Чтобы
расширение попало в каталог:
1. Сделайте pull request: файл расширения в `msx/extensions/` и запись в
   `catalog.json`.
2. Запись выглядит так:
   ```json
   { "name": "Привет", "description": "Что оно делает — одной фразой", "url": "hello.js" }
   ```
3. Код в каталоге проверяется перед выкладкой.

### Отладка

- Ошибки расширения видны в его меню («Настройки → Расширения» → ОК на
  плитке) и на плитке («⚠ Ошибка»).
- `console.log` из расширения пишется в консоль браузера, в контексте его
  iframe.
- В Chrome на ПК откройте TorrStream и нажмите F12. Расширения запускаются
  через пару секунд после главной.
