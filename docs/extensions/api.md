# Справочник API

Всё, что расширению доступно, лежит в глобальном объекте `TS`. Код пишите на
ES5 (`var`, `function`, без стрелок и шаблонных строк). На части телевизоров
браузер — Chrome 53–66.

## Описание расширения

```js
TS.register({ name: 'Название', version: '1.0', description: 'Что делает', settings: true });
TS.info();   // { id, appVersion, platform, features }
```
`features` — что умеет этот TorrStream: `capture-keys`, `focus-home-row`,
`open-row`, `open-category`, `recommend`, `button-placement`, `button-style`,
`online`, `player`, `detail` (см. ниже). Версии с ним отвечают
`appVersion: 2`; на старых (`appVersion: 1`) поля нет — проверяйте, прежде чем
пользоваться:
```js
var F = TS.info().features || [];
if (F.indexOf('capture-keys') !== -1) { /* … */ }
```
`settings: true` добавляет в меню расширения кнопку «Открыть», которая
присылает событие `settings`.

## События

```js
TS.on('detail', function (item) { … });   // открыта карточка фильма или сериала
TS.on('screen', function (name) { … });    // home | torrents | catalog | search | detail | player | config
TS.on('button', function (e) { … });       // нажата ваша кнопка в карточке: { id, item }
TS.on('online', function (e) { … });       // нажата «Онлайн» и выбран ваш источник: { item }
TS.on('player', function (e) { … });       // ваше видео: start | ended | exit (см. «Онлайн-просмотр»)
TS.on('settings', function () { … });      // «Открыть» в меню расширения
TS.on('panel', function (e) { … });        // ваше окно открыто/закрыто: { open }
TS.on('key', function (dir) { return true; });  // пульт: up | down | left | right | enter | back
TS.on('nav', function (e) { … });          // после каждой стрелки и ОК
TS.on('home', function () { … });          // ряды главной построены или пересобраны
TS.off(name, fn);
```

**item** — открытые сведения TMDB о фильме:
```js
{ tmdbId: '603', type: 'movie' | 'tv', title, originalTitle, originalLanguage, year,
  poster, backdrop, vote, imdbId: 'tt0133093', kinopoiskId: '301',
  seasons: [{ season: 1, episodes: 10, name: 'Сезон 1' }], torrent }
```
`imdbId`, `seasons` (только у сериалов, без нулевого «Спецматериалы») и
`kinopoiskId` бывают `null`: первые два приходят, когда TMDB ответит на
запрос карточки, а Кинопоиск известен не у всех подборок. Свежие сведения
открытой карточки — `TS.app.detail()` (Promise, `null` — карточка не открыта);
`button` и `online` приносят свежие сами.
Хеша раздачи, magnet-ссылки и адресов серверов в нём нет. `torrent: true`
означает, что открыта карточка раздачи, а не фильма.

**nav**:
```js
{ key: 'left', screen: 'home', moved: false, focused: { …описание элемента… } }
```
`moved: false` на стрелке означает край: дальше идти некуда. Так открывают
своё боковое меню «влево с первой карточки».

**key** приходит, пока открыто ваше окно (`TS.panel.open`) или пока вы держите
пульт (`TS.keys.capture`). Обработчик, вернувший `true`, отменяет стандартное
поведение. В окне стандартное поведение такое: стрелки двигают фокус между
`button`, `a[href]` и `[data-focus]` рядами, ОК нажимает. Влево-вправо —
только внутри своего ряда; вверх-вниз — в ближайший ряд, на элемент с классом
`on` (выбранная озвучка, сезон), а если такого нет — на ближайший по
горизонтали. Клавиши, нажатые после щелчка мышью по окну, приходят так же.

## Хранилище

Своё у каждого расширения, лимит около 1 МБ JSON. К моменту запуска кода оно
уже загружено, поэтому `get` синхронный, а запись сохраняется сама.
```js
TS.storage.get('key', defaultValue);
TS.storage.set('key', value);    // всё, что переживает JSON
TS.storage.remove('key');
TS.storage.keys();
TS.storage.clear();
```
Когда расширение удаляют, его хранилище удаляется вместе с ним.

## Оформление и карточка

```js
TS.ui.addStyle('.home-card { border-radius: 0 }');
TS.ui.hide('#home-hero .home-hero-actions');
TS.ui.setText('.some-label', 'Текст');            // только элементы без вложенных
TS.ui.addButton({ id: 'x', label: 'Подпись', icon: 'star' });  // в карточке, до 3
TS.ui.updateButton('x', { label: 'Другая', hidden: true });
TS.ui.removeButton('x');
TS.ui.detailButtons();                            // Promise: кнопки строки по порядку
TS.ui.setDetailBlock('<b>HTML</b>');              // блок под описанием карточки; '' — убрать
TS.toast('Сообщение');
```
- `icon` — имя значка [uicons](https://www.flaticon.com/uicons) без приставки:
  `star` → `fi-rr-star`.

### Кнопки в карточке: место и вид

Кнопка встаёт в строку действий карточки в том же стиле, что кнопки
приложения, и пульт ходит по ней как по своим.
```js
TS.ui.addButton({
  id: 'kp', label: 'Кинопоиск', icon: 'link',
  after: 'trailer',          // или before: 'favorite'; или position: 'start' | 'end'
  style: 'round'             // 'round' | 'wide' | 'primary'
});
TS.ui.addButton({ id: 'more', label: 'Ещё', icon: 'menu-dots', after: 'ext:kp' });  // за своей
TS.ui.updateButton('kp', { hidden: !item.imdbId });   // только переданные поля
```
- **Место** — ключ кнопки приложения в `before` или `after`:
  `resume` («Продолжить»), `torrents`, `online` (общая «Онлайн»), `best`,
  `play`, `overview` («Подробнее»), `open-card`, `favorite`, `trailer`; или
  `ext:<id>` своей кнопки. Без места — в конец строки. Спрятанная сейчас
  кнопка приложения якорем остаётся: ваша встанет там, где появилась бы она.
  Несколько кнопок у одного якоря стоят в порядке добавления.
- **Вид**: `round` (по умолчанию) — круг со значком и подписью под ним, как
  «Трейлер»; `wide` — «пилюля» со значком и текстом; `primary` — белая, как
  «Продолжить», для главного действия. На телефоне все кнопки карточки —
  круги, `wide` и `primary` тоже.
- `TS.ui.detailButtons()` отдаёт `[{ key, label, visible, own }]` — какие
  кнопки сейчас в строке: по ним выбирают якорь. Чужих кнопок расширений в
  списке нет.
- Повторный `addButton` с тем же `id` заменяет кнопку целиком,
  `updateButton` меняет только переданное (`label`, `icon`, `style`,
  `hidden`, место).
- В CSS нельзя `url()`, `image-set()`, `@import`, `@font-face` и обратную
  косую черту: ими можно было бы вынести значения полей на чужой сервер.
- HTML блока чистится по белому списку тегов (`div span p b i u s strong em
  small br hr ul ol li h3–h5 img table…`) и атрибутов (`class`, `style`,
  `title`, у `img` — `src` по https или `data:image`). Скрипты и обработчики
  удаляются.

## Своё окно

```js
TS.panel.open('подзаголовок');   // документ расширения во весь экран
TS.panel.close();
TS.panel.focus(element);         // фокус пульта на элемент вашего окна
```
Окно рисует документ самого расширения (`document.body`). Ему доступны обычный
DOM и стили. Фокус пульта обозначается классом `.focused`, а цвет фокуса из
«Внешнего вида» лежит в `var(--focus-color)`. Заголовок с именем расширения
рисует приложение. «Назад» всегда закрывает окно.

## Мост к интерфейсу приложения

Через мост расширение меняет сам интерфейс: вставляет свои элементы, двигает
фокус, строит меню. Элементы приходят описаниями:
```js
{ h, tag, id, cls, text, attrs, own, focused, visible, rect }
```
`h` — номер элемента для следующих вызовов. Вместо него можно передать само
описание. Все методы возвращают Promise.

```js
TS.dom.query('.catalog-row-card', { root, limit, rect: true, text: false });  // до 500
TS.dom.closest(node, '.catalog-row');
TS.dom.children(node);
TS.dom.focused();                          // элемент под фокусом пульта
TS.dom.create('<aside id="ext-menu">…</aside>', { parent: node | 'селектор', where: 'append' | 'prepend' | 'before' | 'after' });
TS.dom.update(node, {
  text: '…', html: '…',                    // html — только у своих элементов
  addClass: 'a b', removeClass: 'c',
  style: { opacity: '.5', display: 'none !important' },
  attrs: { 'data-x': '1', title: null }    // null — убрать
});
TS.dom.remove(node);                       // только свои
TS.dom.click(node);
TS.dom.focus(node);                        // фокус пульта, как стрелкой
TS.dom.on('#ext-menu .item', 'click', function (node) { … });   // мышь и палец
```

Пульт и главная:
```js
TS.keys.capture(true);    // пульт целиком вам: стрелки и ОК приходят событием key
TS.keys.capture(true, { keys: ['up', 'down'] });   // только эти кнопки (capture-keys)
TS.keys.capture(false);   // вернуть пульт приложению
TS.app.home();            // ряды главной
TS.app.item(node);        // сведения о фильме за карточкой
TS.app.screen();          // текущий экран
TS.app.openRow(index);    // ряд главной по номеру (open-row)
TS.app.openCategory(key); // категория каталога по ключу плитки (open-category)
```
- `capture` с `keys` забирает только перечисленные кнопки (`up`, `down`, `left`,
  `right`, `enter`, `back`), остальные работают в приложении как обычно; стрелки и
  ОК дают события `nav`. Так своё меню или своя сетка ведут стрелки, а ОК остаётся
  приложению: оно запускает серию, открывает карточку. Пустой список или список
  без известных кнопок ничего не захватывает.
- «Назад» возвращает пульт приложению всегда, даже если его нет в `keys`: тогда он
  работает в приложении как обычно, а расширению приходит `key` со значением `back`.
- `openRow(index)` — номер ряда из `TS.app.home()`. Ставит фокус на карточку, где в
  ряду стояли; ряд может быть спрятан. Не с главной — открывает её, как «Главная» в
  шапке.
- `openCategory(key)` — ключ плитки категории, её атрибут `data-home-cat`
  (`movie`, `tv`, `anime`…). С главной — как ОК на плитке; из сетки другой
  категории — сразу новая сетка, без возврата на главную: она заменяет прежнюю, и
  «Назад» ведёт туда же, куда вела та (на главную или в ряды каталога).
- `openRow` и `openCategory` работают только на главной, в каталоге и в «Моих
  торрентах», когда поверх ничего не открыто (карточка фильма или раздачи, окно,
  клавиатура), и только в ответ на человека: в течение 2 секунд после кнопки
  пульта, которая пришла расширению (`key` или `nav`). Один переход без нажатия
  разрешён в первые 20 секунд после запуска расширения — открыть главную на
  нужном разделе. Иначе Promise отклоняется: расширение не уводит человека само.
- `TS.dom.focus` на карточку ряда главной работает и для спрятанного ряда:
  главная переключается на него (`focus-home-row`).

Рекомендуемые настройки «Внешнего вида» (`recommend`):
```js
TS.app.recommend({ catalogColumns: '4', heroTrailers: false });
```
Сами не применяются: в меню расширения появляется строка «Рекомендует: …» с тем,
что поменяется, и кнопка «Применить рекомендуемые настройки», пока они отличаются
от текущих. Применяется ровно показанное в меню. Рекомендации живут, пока
расширение запущено, — присылайте их при каждом запуске. Ключи и значения:
- `catalogColumns` — колонки каталога: `auto`, `3`–`8`;
- `heroTrailers`, `showRatings`, `showYear` — да/нет;
- `cardSize` — число, приводится к шагу и пределам ползунка «Размер карточек»;
- `density`: `compact`, `comfortable`, `spacious`;
- `borderRadius`: `none`, `small`, `medium`, `large`;
- `animations`: `none`, `reduced`, `normal`;
- `posterBrightness`: `dim`, `normal`, `bright`.

Да/нет — `true`/`false` (строки `'true'`/`'false'` тоже понимаются). Остальные
ключи и недопустимые значения отбрасываются.

`TS.app.home()` возвращает:
```js
{ ready: true, activeRow: 2, rows: [
  { index, key, title, col, h, cards: [ { h, title, tile, item } ] }
] }
```
`col` — на какой карточке стояли в ряду, `tile: true` — плитка категории,
`item` — сведения о фильме (как в `detail`).

Правила моста:
- **Свои элементы** помечаются `data-ext`. Расширение может наполнять их
  разметкой и удалять. Их `id` должен начинаться с `ext-`.
- **Элементы приложения** можно менять ограниченно: классы, стили, атрибуты
  `data-*`, `aria-*`, `title`, `role`, `hidden`, текст элементов без вложенных.
  Когда расширение выключают, все такие правки откатываются.
- **Нажимать** можно свои элементы и навигацию: пункты шапки, карточки,
  плитки категорий, кнопки карточки (кроме «Избранного»), карточки актёров,
  серий и похожих.
- **Закрыто полностью**: экран настроек, поля паролей, встроенная клавиатура,
  окна расширений. Значения полей ввода не отдаются нигде.
- `TS.keys.capture` возвращается приложению само по «Назад» и при смене
  экрана: в этот момент приходит `key` со значением `back`. Если «Назад» не в
  списке `keys`, он работает в приложении, но пульт возвращается так же.

## Онлайн-просмотр

Расширение может быть источником фильмов и сериалов по прямым ссылкам — как
онлайн-плагины Lampa.
```js
TS.online.register({ name: 'Мой источник', types: ['movie', 'tv'] });   // types — необязательно

TS.on('online', function (e) {
  // e.item — сведения карточки (imdbId, kinopoiskId, seasons…). Ищем видео,
  // показываем выбор в своём окне:
  TS.panel.open('онлайн');
});

TS.player.play({
  url: 'https://cdn.example/film.m3u8',     // или quality — тогда берётся лучшее
  quality: { '1080p': 'https://…/1080.mp4', '720p': 'https://…/720.mp4' },
  title: 'Фильм (2024)',
  poster: 'https://…/poster.jpg',
  subtitles: [{ label: 'Русские', url: 'https://…/ru.vtt', language: 'ru', default: true }],
  startAt: 600                               // с какой секунды
}).then(function () { /* видео пошло */ }, function (err) { TS.toast(err.message); });
```
- `TS.online.register` добавляет в карточку фильма **одну общую кнопку
  «Онлайн»** (сразу за «Торрентами»). Источников несколько — приложение
  спрашивает, какой открыть, и помнит последний выбор. Нажали — вашему
  расширению приходит `online` с `item`. Карточке раздачи кнопка не
  показывается. `TS.online.unregister()` убирает источник.
- **Сериал** — плейлистом: `playlist: [{ url | quality, title, season,
  episode, subtitles }]` и `index` — с какой серии начать (или `url` текущей).
  Дальше плеер переключает серии сам, по настройке «Переключать серии
  автоматически».
- **Где играет**: в Android-приложении — его плеер (встроенный или выбранный
  внешний): качества, субтитры, плейлист и `headers` (`{ 'User-Agent': … }`)
  он понимает. В остальных — встроенный веб-плеер: `m3u8` через hls.js (или
  сам браузер телевизора), остальное — тегом `<video>`; субтитры источника —
  в меню «Онлайн субтитры». `headers` веб-плеер не умеет.
- **Только в ответ на человека**: пока открыто ваше окно или 15 секунд после
  его кнопки, «Онлайн» или клавиши, пришедшей вам. Иначе — отказ.
- **Адреса** — по правилам `TS.fetch` (ниже): не домашняя сеть и не серверы
  TorrStream. Для `m3u8` в веб-плеере источник должен отдавать CORS; для
  `mp4` — не обязательно. Субтитры веб-плеер скачивает сам — им CORS нужен.
- Окно расширения перед запуском закрывается само; «Назад» в плеере
  возвращает в карточку.

Событие `player` (на Android приходит только `start`):
```js
TS.on('player', function (e) {
  // { state: 'start', index, url, player: 'web' | 'android' }
  // { state: 'ended', index, position, duration }  — серия доиграла
  // { state: 'exit', reason, index, url, position, duration } — из плеера вышли
  if (e.state === 'exit' && e.position > 10) TS.storage.set('pos', Math.floor(e.position));
});
```

## Сеть

```js
TS.fetch(url, { method: 'GET', headers: {}, body: null }).then(function (r) {
  return r.json();     // r: { ok, status, url, text(), json() }
});
```
- Запрос выполняет приложение: без cookie и без Referer.
- Ответ — до 2 МБ, ожидание — до 15 секунд.
- Сервер должен отдавать заголовок CORS (`Access-Control-Allow-Origin`).
- Закрыты адреса сервера TorrStream, TorrServer, самой страницы и домашней
  сети (10.x, 192.168.x, 127.x, `.local` и т. п.).
- Перенаправления разрешены только у GET и HEAD, и конечный адрес проходит ту
  же проверку.
- Обычные `fetch`, `XMLHttpRequest` и `WebSocket` в песочнице закрыты.
- Картинки в своём окне и в блоках грузятся только по https.
