Не находит торренты

Настроим, где приложение ищет раздачи.

  1. Откройте настройки трекеров

    ⚙️ Настройки›Настройки торрентов›Настройки торрент-трекеров

  2. Выключите все переключатели

    RuTor, NUMParser, TorrServer, MegaPeer и остальные — все в положение выкл.

  3. Включите только два

    • Поиск c Torrs — выкл.
    • Поиск c Jackett — вкл.

  4. Поля адресов оставьте пустыми

    Адрес Torrs и Адрес Jackett — ничего не вписывайте, приложение выберет само.

Всё равно не работает?
Поиск медленный или не работает

Выключите Поиск c Torrs и оставьте включённым только Поиск c Jackett.

Пишет «Нет результата»

  1. Поищите по оригинальному названию

    Например, не «Дюна», а «Dune».

  2. Проверьте, вышел ли фильм в цифре

    Поищите в интернете «название + цифровой релиз». Если фильм только в кино — хороших раздач ещё нет.

  3. Хотите смотреть даже в плохом качестве?

    ⚙️ Настройки›Настройки торрентов›Настройки качества торрентов

    Включите Выдавать торренты с низким качеством.

  4. Или впишите свой Jackett из списка ниже

    В поле Адрес Jackett (и Jackett API Key, если он указан). Проверить, работает ли Jackett, можно, открыв его ссылку.

Нет названий фильмов

Или старая дата обновления, или в подборках 0.

  1. Откройте настройки данных

    ⚙️ Настройки›Управление данными

  2. Выберите источник

    Источник данных приложения → YouROK

  3. Оставьте ссылку пустой

    Поле Ссылка на свой источник данных — ничего не вписывайте.

    Не помогло? Впишите туда любой источник из списка ниже.
