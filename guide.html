Решение проблемы с отображением постеров

Способ 1: Изменение настроек

Перейдите в Настройки → Информация о видео и установите одну из следующих комбинаций:

ВНИМАНИЕ! ПОСЛЕ СМЕНЫ НАСТРОЕК ТРЕБУЕТСЯ ПЕРЕЗАПУСК ПРИЛОЖЕНИЯ!

ДВОЙНЫМ НАЖАТИЕМ КЛАВИШИ "НАЗАД" ИЛИ ДОЛГИМ УДЕРЖАНИЕМ КЛАВИШИ "НАЗАД", ИЛИ "НАСТРОЙКИ ANDROID -> ПРИЛОЖЕНИЯ -> NUM -> ОСТАНОВИТЬ", ИЛИ ВЫКЛЮЧИТЬ УСТРОЙСТВО ИЗ РОЗЕТКИ!

Чтобы проверить какая комбинация у вас будет рабочая попробуйте открыть ссылки ниже

Torrs | Johnny | Lampa | TMDB ← нажимать на эти надписи!

Если открылась ссылка с названием "Torrs" тогда ваша комбинация одна из

torrs, torrs, num dns
torrs, torrs, quad9 doh
TMDB, torrs, num dns
TMDB, torrs, quad9 doh

Если открылась ссылка с названием "Johnny" тогда ваша комбинация одна из

Johnny, Johnny, num dns
Johnny, Johnny, quad9 doh
TMDB, Johnny, num dns
TMDB, Johnny, quad9 doh

Если открылась ссылка с названием "Lampa" тогда ваша комбинация одна из

tmdb, Lampa, num dns
torrs, Lampa, num dns
Johnny, Lampa, num dns
tmdb, Lampa, quad9 doh
torrs, Lampa, quad9 doh
Johnny, Lampa, quad9 doh

Если открылась ссылка с названием "TMDB" тогда ваша комбинация одна из

tmdb, tmdb, num dns
tmdb, tmdb, quad9 doh

Решение проблемы с поиском торрентов

Настройка торрент-трекеров:

1. Зайдите в Настройки → Настройки торрентов → Настройки торрент-трекеров

2. Отключите все галочки

3. Включите только torrs и jackett

4. Адреса torrs и jackett оставьте пустыми

Если поиск не работает:

1. Отключите torrs

2. Воспользуйтесь любым доступным jackett из списка ниже

3. Проверить доступен ли jackett можно перейдя по его ссылке
