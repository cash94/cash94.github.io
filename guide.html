Решение проблемы с отображением постеров

Способ 1: Изменение настроек

Перейдите в Настройки → Информация о видео и установите одну из следующих комбинаций:

torrs, torrs, num dns
tmdb, tmdb, quad9 doh
tmdb, Johnny, num dns
tmdb, Johnny, quad9 doh

Способ 2: Использование прокси-серверов

Для отображения постеров можно использовать прокси:

  • Сервер Api Tmdb - Tmdb
  • Сервер изображений - Tmdb
  • Доступ к Tmdb - использовать прокси-сервер

Решение проблемы с поиском торрентов

Настройка торрент-трекеров:

1. Зайдите в Настройки → Настройки торрентов → Настройки торрент-трекеров

2. Отключите все галочки

3. Включите только torrs и jackett

4. Адреса torrs и jackett оставьте пустыми

Если поиск не работает:

1. Отключите torrs

2. Воспользуйтесь любым доступным jackett из списка ниже

3. Проверить доступен ли jackett можно перейдя по его ссылке

Решение проблемы с отображением названий фильмов и сериалов

2. Установите источник данных: "Yourok"

3. Поле "Ссылка на свой источник данных" оставьте пустым

4. Или укажите любой доступный вам источник данных из списка ниже
